### 👨‍💻 How to Contribute
We welcome developers, designers, marketers, and testers who believe in empowering the creator economy.

**Tech stack:**
- **Frontend**: Next.js, React, Tailwind CSS
- **Backend**: Node.js, Google Cloud, Firebase
